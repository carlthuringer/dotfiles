** How to do literate configuration?
   It's entirely done with tangle and source blocks. 

   The other trick to doing literate is to use =noweb= to organize
   code snippets into the target file, so that you aren't forced to
   organize your document based on the structure of the eventual code
   file.
   #+begin_example
     ,#+begin_src elisp :tangle ~/.config/emacs/init.el :mkdirp yes :noweb yes
       <<bootstrapping>>
     ,#+end_src
   #+end_example
** Noweb Header Arg
   You can make all source blocks in a heading tangle together by
   placing a property in the Properties drawer. Invoke =C-c C-x p=
   and enter:
   #+begin_example
     :header-args: :noweb-ref reference-name
   #+end_example
** What version of Emacs are we targeting?

* Early Init
  Frame appearance and startup tuning that must happen before the GUI
  initializes. This tangles to a separate early-init file, so it's an
  exception to the =noweb-ref= scheme.

  #+begin_src elisp :tangle ~/.config/emacs/early-init.el :mkdirp yes
    ;; Some things from emacs bedrock!
    ;; https://git.sh.ht/~ashton314/emacs-bedrock

    ;; Startup speed, annoyance suppression
    (setq gc-cons-threshold 10000000)
    (setq byte-compile-warnings '(not obsolete))
    (setq warning-suppress-log-types '((comp) (bytecomp)))
    (setq native-comp-async-report-warnings-errors 'silent)

    ;; Silence stupid startup message
    (setq inhibit-startup-echo-area-message (user-login-name))

    ;; Default frame configuration: full screen, good-looking title bar on macOS
    (setq frame-resize-pixelwise t)
    (tool-bar-mode -1)                      ; All these tools are in the menu-bar anyway
    (menu-bar-mode -1)
    (setq default-frame-alist '((fullscreen . maximized)

                                ;; Setting the font here (rather than with
                                ;; set-face-font at init time) covers
                                ;; emacsclient/daemon frames and avoids a
                                ;; font flash at startup.
                                (font . "Fira Code-14")

                                ;; You can turn off scroll bars by uncommenting these lines:
                                ;; (vertical-scroll-bars . nil)
                                ;; (horizontal-scroll-bars . nil)

                                ;; Setting the face in here prevents flashes of
                                ;; color as the theme gets activated
                                (background-color . "#000000")
                                (ns-appearance . dark)
                                (ns-transparent-titlebar . t)))
          
  #+end_src

** =read-process-output-max=
   How many bytes to read from a subprocess in a single chunk. It
   defaults to 64kB; language servers send large JSON payloads, so up
   it to 1MB.
   #+begin_src elisp
     (setq read-process-output-max (* 1024 1024))
   #+end_src

* Bootstrapping
  :PROPERTIES:
  :header-args: :noweb-ref bootstrapping
  :END:
  Package management is entirely built-in: package.el installs from
  the GNU and NonGNU ELPA archives (enabled by default) plus MELPA,
  configured through [[https://github.com/jwiegley/use-package][use-package]] (bundled since Emacs 29). The =:vc=
  keyword (new in Emacs 30) covers the rare package that lives only on
  a git forge.
   
** Package archives
   GNU and NonGNU ELPA are present by default; add MELPA.
   #+begin_src elisp
     (require 'package)
     (add-to-list 'package-archives '("melpa" . "https://melpa.org/packages/") t)
   #+end_src

** Make sure that Homebrew info directory is loaded if present
Homebrew keeps info files in =/opt/homebrew/share/info=. They won't show
up in emacs' info browser unless they're added to the =Info-directory-list=
#+begin_src elisp
  ;; Info-additional-directory-list is merged into the search path when
  ;; info initializes; pre-seeding Info-directory-list at startup would
  ;; suppress the default path computation entirely.
  (with-eval-after-load 'info
    (add-to-list 'Info-additional-directory-list "/opt/homebrew/share/info"))
#+end_src

#+begin_src elisp
  (defvar crt/org-present-previous-themes nil
    "Themes that were active before `org-present' started.")

  (defun my/org-present-start ()

    ;; Tweak font sizes
    (setq-local face-remapping-alist '((default (:height 1.5) variable-pitch)
                                       (header-line (:height 4.0) variable-pitch)
                                       (org-document-title (:height 1.75) org-document-title)
                                       (org-code (:height 1.55) org-code)
                                       (org-verbatim (:height 1.55) org-verbatim)
                                       (org-block (:height 1.25) org-block)
                                       (org-block-begin-line (:height 0.7) org-block)))

    ;;Create empty header space
    (setq header-line-format " ")

    ;; Center the presentation and wrap lines
    (visual-fill-column-mode 1)
    (visual-line-mode 1)

    ;; Remember whatever themes are active (auto-dark may have chosen
    ;; light or dark) and force the dark theme for presenting.
    (setq crt/org-present-previous-themes custom-enabled-themes)
    (load-theme 'solarized-selenized-dark t)

    (set-face-attribute 'org-block nil :foreground nil :inherit 'fixed-pitch)
    (set-face-attribute 'org-table nil :inherit 'fixed-pitch)
    (set-face-attribute 'org-formula nil :inherit 'fixed-pitch)
    (set-face-attribute 'org-code nil :inherit '(shadow fixed-pitch))
    (set-face-attribute 'org-verbatim nil :inherit '(shadow fixed-pitch))
    (set-face-attribute 'org-special-keyword nil :inherit '(font-lock-comment-face fixed-pitch))
    (set-face-attribute 'org-meta-line nil :inherit '(font-lock-comment-face fixed-pitch))
    (set-face-attribute 'org-checkbox nil :inherit 'fixed-pitch)

    )

  (defun my/org-present-end ()
    ;; reset fonts
    (setq-local face-remapping-alist '(((default variable-pitch default))))

    (setq header-line-format nil)

    (visual-fill-column-mode 0)
    (visual-line-mode 0)
    ;; Restore whatever was active before the presentation (auto-dark
    ;; may have chosen either).
    (dolist (theme custom-enabled-themes)
      (disable-theme theme))
    (dolist (theme (reverse crt/org-present-previous-themes))
      (enable-theme theme))
    )

  (defun my/org-present-prepare-slide (buffer-name heading)
    ;; Show only top-level headlines
    (org-overview)
    ;; Unfold the current entry
    (org-show-entry)
    ;; Show only direct subheadings of the slide but don't expand them
    (org-show-children))

  (use-package visual-fill-column
    :custom
    (visual-fill-column-width 110)
    (visual-fill-column-center-text t))
  (use-package org-present
    :after visual-fill-column
    :hook ((org-present-mode . my/org-present-start)
           (org-present-mode-quit . my/org-present-end))
    :init
    (add-hook 'org-present-after-navigate-functions 'my/org-present-prepare-slide))

** Inline diagnostics (flymake + sideline)
Eglot reports diagnostics through =flymake=, which is built into Emacs. By
default flymake marks the fringe and shows the message in the echo area only
when point is on the offending line. For a VS Code "Error Lens" feel I want the
message to ride the end of the current line, always visible.

[[https://github.com/emacs-sideline/sideline][sideline]] renders annotations in the right margin, and
[[https://github.com/emacs-sideline/sideline-flymake][sideline-flymake]] feeds flymake diagnostics into it. Hooking on =flymake-mode=
means this lights up in every eglot-managed buffer (CUE included) without a
per-language hook. =sideline-flymake-display-mode= set to ='line= shows the
diagnostics for the whole current line rather than only the one under point.

=flymake-no-changes-timeout= is how long flymake waits after a change before
re-checking. For eglot buffers diagnostics are pushed by the server (see
=eglot-send-changes-idle-time= in the Eglot section), so this mainly governs
non-LSP flymake backends; raised to match so nothing rechecks too eagerly.

The delay above governs how soon errors *appear*, but I also want them to
*disappear* the instant I resume typing — not linger for three stale seconds
while I fix them. Flymake has no built-in knob for that asymmetry: its timeouts
only schedule when the next check starts, never clear what's shown. So a small
buffer-local =after-change-functions= hook clears Flymake's diagnostics on every
edit. The fringe, echo area, and sideline all read from Flymake's diagnostic
overlays, so clearing those clears every display at once — no sideline code
involved. I use Flymake's own =flymake--clear-state= rather than deleting
overlays by hand because it also nils the per-backend bookkeeping list, keeping
state consistent for the next server report (which only does a full cleanup on
its *first* report). Fresh diagnostics reappear when the backend next reports,
after the idle delay.
#+begin_src elisp
  (use-package flymake
    :ensure nil
    :custom
    (flymake-no-changes-timeout 3.0)
    :hook (flymake-mode . crt/flymake-clear-on-edit-setup)
    :preface
    (defun crt/flymake-clear-diagnostics-on-edit (&rest _)
      "Immediately drop shown Flymake diagnostics on any buffer edit.
  They reappear when the backend next reports, so errors clear the
  instant I type but only re-appear after the idle delay."
      (when (hash-table-p flymake--state)
        (maphash (lambda (_backend state) (flymake--clear-state state))
                 flymake--state)))
    (defun crt/flymake-clear-on-edit-setup ()
      "Add or remove the clear-on-edit hook with `flymake-mode'."
      (if flymake-mode
          (add-hook 'after-change-functions
                    #'crt/flymake-clear-diagnostics-on-edit nil t)
        (remove-hook 'after-change-functions
                     #'crt/flymake-clear-diagnostics-on-edit t))))
#+end_src

#+begin_src elisp

** [[https://github.com/russell/cue-mode][CUE mode]]
CUE definitions are written with a leading =#= (e.g. =#Renderable=), and
=cue lsp= returns completion candidates that include that =#=. But cue-mode's
syntax table leaves =#= as punctuation, so Emacs computes the completion region
as starting /after/ the =#=. When cycling candidates in Corfu (whose
=corfu-preview-current= inserts the selection inline) the full =#...= candidate
gets dropped in after the existing =#=, doubling it (=tools.##ValuesConfigMap=).
Giving =#= symbol-constituent syntax makes the completion field include the =#=
so candidates replace it cleanly.
#+begin_src elisp

    :config
    (modify-syntax-entry ?# "_" cue-mode-syntax-table))
#+end_src

** Org Journal
One thing I've noticed with using =org-roam-dailies= is that I create a bunch of daily journal entries but then never revisit them. In fact it's not very useful for just capturing how I'm feeling or browsing back through the days. I found myself starting to link to other roam documents from the journal, and even then didn't find it super useful to check the daily backlinks. Really I want my journal to be browseable, and so I think the best way to represent the journal is in a continuous text file.

Therefore I happened upon [[https://github.com/bastibe/org-journal][org-journal]], which seems to do exactly what I want.

I will configure org-journal to place my journals in =~/org/journal=, and use a yearly file format. It owns =C-c c=.
#+begin_src elisp :noweb yes :no-export yes
  (use-package org-journal
    :demand t
    :commands (org-journal-new-entry)
    :bind ("C-c c" . org-journal-new-entry)
    :custom
    (org-journal-dir "~/Documents/org/journal")
    (org-journal-file-type 'yearly)
    (org-journal-file-format "%Y.org")
    (org-journal-date-format "%A, %Y-%m-%d")
    :preface
    <<org-journal-preface>>
    :bind
    <<org-journal-bind>>
    )
#+end_src
*** Close Org Journal when I save the entry (like org-capture)
This is a neat snippet found on the github page for org-journal:
#+begin_src elisp :noweb-ref org-journal-preface
  (defun crt/org-journal-save-entry-and-exit()
    "Simple convenience function.
    Saves the buffer of the current day's entry and kills the window
    Similar to org-capture like behavior"
    (interactive)
    (save-buffer)
    (kill-buffer-and-window))
#+end_src

#+begin_src elisp :noweb-ref org-journal-bind
  (:map org-journal-mode-map
        ("C-x C-s" . crt/org-journal-save-entry-and-exit))
#+end_src
